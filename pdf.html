Project 1: Learning Management System (LMS)

1.1 Refactor Code dan Optimasi Performance

Melakukan refactoring kode untuk mengimplementasikan sistem pengambilan data secara on-demand dan asynchronous. Perubahan arsitektur dari eager loading menjadi lazy loading untuk meningkatkan performa aplikasi. Data detail tidak langsung diambil di awal, melainkan di-fetch ketika dibutuhkan oleh user.

Keuntungan Implementasi On-Demand Fetch:

  • Peningkatan kecepatan load awal halaman karena hanya memuat data yang essential
  • Efisiensi bandwidth dengan hanya mengambil data yang benar-benar diperlukan user
  • Skalabilitas lebih baik karena server tidak terbebani dengan query data yang tidak terpakai
  • User experience lebih responsif dengan loading state yang tepat
  • Optimasi resource database dengan query yang lebih spesifik dan targeted
  • Maintenance lebih mudah karena kode lebih modular
Teknologi: Laravel, Alpine.js

Project 2: Palembang Nearby

2.1 Konsep dan Fitur Utama

Platform digital untuk menampilkan katalog produk UMKM lokal Palembang dengan fitur pencarian berdasarkan lokasi terdekat dari user. Sistem ini membantu UMKM dalam digitalisasi dan mempermudah customer menemukan produk lokal. UMKM dapat mendaftar dan mengelola toko mereka sendiri melalui platform ini.

Fitur Utama Platform:

  • Katalog produk UMKM dengan informasi lengkap
  • Menampilkan toko UMKM terdekat berdasarkan lokasi user
  • Sistem registrasi untuk UMKM
  • Interface yang user-friendly untuk customer dan UMKM
Teknologi: Laravel, Inertia.js, React

2.2 Progress Pengembangan

Project sedang dalam fase pengembangan awal dengan setup infrastruktur dan implementasi fitur-fitur fundamental.

Yang Sudah Dikerjakan:

  • Instalasi project dengan Laravel, Inertia.js, dan React
  • Pembuatan halaman landing/homepage
  • Implementasi sistem login untuk user dan UMKM
  • Pembuatan sistem registrasi dengan stepper yang mencakup:
    • Step 1: Informasi akun (username, email, password)
    • Step 2: Informasi toko (nama toko, deskripsi, kategori)
    • Step 3: Lokasi dan kontak (alamat, koordinat, nomor telepon)
    • Step 4: Verifikasi dan konfirmasi

Rencana Selanjutnya:

  • Dashboard UMKM untuk manage produk dan toko
  • Implementasi fitur location-based search dan mapping
  • Sistem katalog produk dengan filter dan search
  • Integration dengan payment gateway
Teknologi: Laravel, Inertia.js, React
